# Derivations

Store derivations here when they are developed. Each document should identify:

1. The claim being derived and its source or motivation.
2. Assumptions, units, metric signature, and index conventions as applicable.
3. Intermediate steps sufficient to check the result.
4. Limiting cases and independent consistency checks.
5. Open questions and the review status.

Link the derivation to the code or experiment that uses it. No derivations have
been completed yet.
