# Mathematics notes

Use this directory for reviewed study notes as the research progresses.
The following is a writing roadmap, not completed course material.

| Topic | Intended connection |
| --- | --- |
| Ordinary differential equations | Initial-value problems, error, and convergence |
| Linear algebra | State vectors and coordinate transformations |
| Vector calculus | Divergence, deformation, and vorticity |
| Partial differential equations | Transport and boundary conditions |
| Tensor calculus | Index conventions and fluid kinematics |
| Differential geometry | Covariant derivatives and spacetime curvature |

Each note should define notation, list prerequisites, cite its sources, include
a worked check, and state where the result applies. Link substantial derivations
from [the derivations directory](../derivations/README.md).
