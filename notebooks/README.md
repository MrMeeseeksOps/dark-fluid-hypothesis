# Notebooks

Reserved for future exploratory analysis and explanatory figures.
Reusable algorithms belong in `src/darkfluid/`, with tests under `tests/`.

Before committing a notebook, clear bulky outputs, document its environment and
data sources, and verify it runs from a fresh kernel in cell order. Put generated
artifacts in the ignored `outputs/` directory and retain evidence separately as
described in [the development guide](../docs/development.md).
